# office_de_tourisme_les_Herbiers

L’objectif de ce projet est de présenter la météo d’un endroit dans une page web d’un office de
tourisme. Pour cela, la page doit accéder à une API afin d’afficher la météo d’un point
géographique.

-Contraintes techniques

Le projet doit être réalisé en JS modulaire grâce au
bundler Webpack. Il doit interroger l’API Open Météo
pour obtenir les prévisions météorologiques d’un
point donné. Pour appeler cette API, il faut utiliser la
bibliothèque JavaScript Axios.

Vous pourrez trouver dans ce repo la documentation technique livrée avec le projet
